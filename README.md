# 📱 Task Manager v2

Приложение для тех, кто хочет навести порядок в делах, но без скучных инструкций. Task Manager v2 — это React Native-проект, который одинаково легко запускается на iOS, Android и в браузере.

---

## 🤟 Что тут вообще есть?

- ✏️ Создание, редактирование и удаление задач без лишних кликов.
- 💾 Хранение данных локально (AsyncStorage) + синхронизация с Supabase, чтобы ничего не потерялось.
- 🔔 Push-уведомления и вход через Google — всё как в серьёзных приложениях.
- 🌗 Светлая и тёмная темы, адаптация под разные экраны.
- 🚥 Приоритеты задач и свежий интерфейс.
- 🪜 Подзадачи с прогресс-баром, чтобы видеть движение дела.

---

## 🧰 Что нужно новичку

1. **Node.js 18+** — скачай с [официального сайта](https://nodejs.org/) и поставь галочку «npm» в установщике.
2. **Git** — чтобы забрать себе проект. Если никогда не ставил, то в Google набери «скачать git» и следуй мастеру установки.
3. **Expo Go** на телефоне (App Store или Google Play) — пригодится, чтобы сразу посмотреть результат.

Когда всё готово — открывай терминал (подойдёт стандартный в macOS, PowerShell в Windows или любая консоль в Linux).

---

## 🚀 Запуск (режим «сделай и не думай»)

```bash
git clone https://github.com/nepovtor/task-manager.git
cd task-manager/TaskManager
npm install
npx expo start
```

Дальше Expo предложит: 

- **Press `w`** — чтобы открыть проект в браузере.
- **Наведись камерой на QR-код** в приложении Expo Go и смотри, как всё работает на телефоне.

Если что-то пошло не так — перезапусти терминал и попробуй снова. Expo обычно сам подсказывает, чего ему не хватает.

## 🧭 Как устроены папки

```
src/
  navigation/  роуты и стеки экранов
  screens/     сами экраны приложения
  services/    API, уведомления, локальное хранилище
  styles/      темы, цвета и стили
server/        Express API для серверного хранения задач
```

Если растерялся — начни с `src/screens`, там живёт основная логика отображения.

---

## 🌐 Серверная часть

В папке `TaskManager/server` лежит простой Express API. Он сохраняет задачи на диске (`data/tasks.json`) и даёт REST-эндпоинты для CRUD-операций.

Быстрый старт:

```bash
cd TaskManager/server
npm install
npm start
```

По умолчанию сервер поднимается на `http://localhost:4000`. Эндпоинты и примеры запросов описаны в `TaskManager/server/README.md`.

# Task Manager Server

Небольшой Express API для серверного хранения задач из приложения Task Manager. API сохраняет данные в `server/data/tasks.json` и готов к запуску локально или развёртыванию на любом Node.js-хостинге.

## Быстрый старт

```bash
cd TaskManager/server
npm install
npm start
```

По умолчанию сервер запускается на `http://localhost:4000`. Порт можно изменить переменной окружения `PORT`.

## Доступные эндпоинты

- `GET /health` — проверка состояния сервиса.
- `GET /tasks` — список всех задач.
- `GET /tasks/:id` — получить задачу по идентификатору.
- `POST /tasks` — создать задачу. Поле `title` обязательно.
- `PUT /tasks/:id` — обновить задачу полностью или частично.
- `PATCH /tasks/:id/status` — изменить только статус задачи.
- `DELETE /tasks/:id` — удалить задачу.

Пример тела запроса для создания задачи:

```json
{
  "title": "Разобрать почту",
  "description": "Оставить только важные письма",
  "status": "in_progress",
  "priority": "high",
  "dueDate": "2025-01-15T12:00:00.000Z",
  "subtasks": [
    { "title": "Удалить спам" },
    { "title": "Ответить на важные письма" }
  ]
}
```

Сервис хранит данные на диске, поэтому после перезапуска данные сохраняются, пока существует файл `data/tasks.json`.
